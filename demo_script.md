SentinelSight Demo Script (3–5 minutes)

1. Open dashboard: http://localhost:8000
2. Add a camera: Click Add Camera and POST an RTSP URL or local file path.
3. Watch camera list show status and snapshot. 
4. Trigger intrusion: Move into a configured zone (or place object in video) to generate an Intrusion event.
5. Show Event Feed: filter by camera and click event to view snapshot and metadata.
6. Open Zone Editor: modify zones JSON and save.

Notes: If no RTSP is available, use a local video file path when adding camera.
